Run sigils — v2

Same rules as v1 (deterministic, one accent, theme-proof) — new anatomy. Type to test:

variant A · comet

One continuous curve, gradient tail, dots on the line

A smooth Catmull-Rom loop through the seeded points — the dots sit on the curve instead of being joined by straight segments, and the stroke fades along a seeded gradient so it reads head→tail. The most "seal-like" of the three.

variant B · gooey

Dots and lines melt into one ink shape

The literal answer to "smoother transition between the dots and lines": a blur + alpha-threshold filter fuses them into a single fluid glyph, then a gradient is masked through it. Perf note: SVG filters at list scale should be pre-rasterized once per id (plan 3.1 covers this).

variant C · thread

Tapered thread with knots

The curve is drawn twice — a wide, faint underlayer and a fine bright core — so it feels tapered and hand-inked; points become "knots" where the thread thickens via a radial glow rather than hard circles.
