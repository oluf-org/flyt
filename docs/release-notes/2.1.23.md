Flyt 2.1.23 adds guided default workflows, sustained Goal campaigns, and clearer evidence for repository work.

- Start common tasks with Make a change, Fix a bug, Review a change, Research a question, Plan an idea, and Deliver a complex task.
- Explore and compare Goal candidates within fixed budgets, retain the baseline when improvements are not verified, and resume saved campaigns.
- See files created, modified, and deleted by a run, with recorded line counts and file-opening actions.
- Start ready tasks as soon as a dispatch slot becomes available and preserve dependency ordering.
- Improve failed-run recovery, read-loop detection, summary deadlines, and Windows shell quoting.
- Restore GitHub installer downloads independently of Cloudflare publication. Releases include SHA-256 checksums.

Installers are unsigned. Windows and macOS may require the usual operating-system confirmation. The app's Cloudflare update channels remain separately managed; publishing these GitHub downloads does not promote an automatic update.
