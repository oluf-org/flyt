# Release Notes — Planned Changes (Draft, Ready for review)

**Status: planned, not yet shipped.** Everything below is planned for the upcoming release and has not shipped yet. Items may change, be delayed, or be dropped before release, and no release date has been announced.

## Planned for the next release

### Fixed — Import cancellation will no longer delete notes (planned)
Today, cancelling an import can delete notes you already had. We plan to fix this so that cancelling an import simply stops the import and leaves your existing notes untouched.

### Improved — Export progress (planned)
We plan to add a progress indicator for exports, so you can see how an export is progressing while it runs.

### Improved — Large-font layout on Android (planned)
We plan layout improvements so screens stay readable and properly arranged when your device uses large system font sizes.

## Before release (planned)
Imports, exports, and large-font layouts are planned for regression testing before this release, and a rollback window is reserved at the end of the schedule in case anything needs to be undone.

## Not planned for this release

- **Cloud sync** — Cloud sync is explicitly out of scope for this release. No cloud sync is planned; your notes remain stored on your device.
