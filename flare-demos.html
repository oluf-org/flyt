Identity & flare

flare 1 · run sigils

Every run gets a generative seal

A tiny constellation derived deterministically from the run id — same run, same sigil, forever. Runs stop being interchangeable list rows; you recognize Tuesday's refactor run. Costs one 26px SVG per row. Type anything:

flare 2 · model glyph language

Shape = model family (colors stay sacred)

Multi-model routing is the app's core, but showing it with colors would break the one-accent rule. Shapes don't: ○ anthropic, ⬡ openai, △ local, ◇ google — used on node chips, edges, and the routing table. Legible at any size, theme-proof, colorblind-proof.

flare 3 · the weight of the work

Token cost as visible physics

Edge thickness ∝ context flowing across it; heavier nodes sit deeper (stronger shadow). A run that balloons context looks heavy — the Context Analysis step (DESIGN-SPEC §3) becomes visually verifiable: pointers-only edges are threads, full-context edges are cables.

flare 4 · blueprint ↔ live

Authoring is a drafting table; running is mission control

Two aesthetics for the two canvas modes you already have (D5). Authoring: monoline dashed "blueprint" with mono annotations — invites editing. Run view: today's filled cards — invites watching. The mode switch stops being a toolbar state and becomes a place change.

flare 11 · two sounds, total

A tick and a chime — nothing else

Sound is the most overused and therefore most avoided channel — which is why exactly two works: a sub-100ms wooden tick on run completion, a soft two-note chime when a gate needs you (the one event worth interrupting for). Off by default in Settings. WebAudio, zero assets:

curation note

If it were mine to prune

You're right that all of this at once = mess. The coherent bundle: tabs B (pills) as the strip + tabs D (deck) as the switcher, then sigils + receipt (one identity: runs are artifacts with seals), blueprint ↔ live (one identity: two rooms), and focus dimming + time travel (pure function, no aesthetic cost). Glyph language ships whenever multi-model routing does. Stamp, machine room, sounds, doodle: keep two at most — they're seasoning, not structure.
