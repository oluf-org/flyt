Run sigils — v4

Four more anatomies, one per symmetry system. Same seeding + hue rules as v3.

variant H · rune

Angular stroke-walk on a 3×3 grid

A seeded 4–6 segment walk across a tiny grid, drawn as one gradient stroke with round joins, plus a start dot. Angular where D–G were all curves — pairs nicely with monospace run ids. Grid quantization means small ids still render crisp.

variant I · burst

Radial ticks with seeded lengths

8–14 evenly spaced rays whose inner/outer radii are seeded, some tipped with a dot. Reads like a compass rose / stamp. Nearly as cheap as v3's orbit, and the length pattern acts as a visual "barcode" of the id.

variant J · circuit

Arc segments on concentric tracks

Three tracks, each carrying 1–2 arc segments with seeded start/sweep, rounded caps, node dots at arc ends. The most "flow run" of any variant so far — it looks like a radial progress/pipeline diagram without literally being one.

variant K · moth

Mirrored constellation

4–5 seeded points in one half, mirrored across the vertical axis, joined by a smooth path and marked with dots. Bilateral symmetry reads as an emblem (moth/mask/crest) — organic like v2's comet but composed instead of scattered.
